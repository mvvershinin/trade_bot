# Общие правила ролей Codex

Сначала AGENTS.md. Приоритет: прямое поручение и последние решения владельца,
текущий HANDOFF/ROADMAP, затем бриф. Унаследованные брифы могут содержать старые
цифры, удалённые режимы и требования автоматических гейтов: не исполнять их без
сверки текущего решения. Бриф — предметная база, не источник текущего статуса.

Подагент не создаёт агентов. Все поручения через корневого координатора.
Модель и effort наследуются, сильнее без разрешения нельзя. Нет механического
соответствия Opus/Sonnet моделям Codex.

Читайте только документы и разделы по задаче. Поиск — в нужных продуктовых
каталогах, без рекурсивного reference/. Большой ответ в файл, в чат не более
15 строк: что сделано, находки/блокеры, вердикт, проверки, путь. Если прав на
запись нет — отчёт верни координатору, файл сохранит он. Без выдуманной проверки.

В каждой находке: назначение пути, достижимый сценарий, вход, фактический эффект,
ссылка на код; не критиковать механизм, не выяснив зачем он нужен. Различай
воспроизведённое и подозрение; не предлагай отменить измеренное решение.

Паттерн ищется до третьей ветки, не ради паттерна. Крупная задача без миниплана —
вернуть координатору недостающее, не начинать скрытую реализацию.
Мутации только вне общего дерева, проверяют поведение задания, не устройство теста.
Токен не читать, не печатать, реальный счёт не использовать. Свои процессы убирать
по PID. Чужие изменения не откатывать. Read-only роли ничего не меняют, включая
отчёты, git, кэши и продуктовые проверки, которые могут писать базу владельца.
