# Решения

Одно решение — один файл. Формат имени: `NNNN-short-name-in-latin.md`.

⚠️ **Имя файла — латиницей, правило 6 [`CLAUDE.md`](../../CLAUDE.md).** Содержимое
русское, имя латинское. 03.09.2026 все двенадцать решений переименованы: кириллица
в имени ломает пути в консоли, в `git` и в сборке Nuitka под Windows, а в выдаче
показывается escape-последовательностями вместо букв. Прежний шаблон здесь велел
обратное — он и был причиной, по которой так завели все двенадцать.

Решение заводится, когда:

- заказчик ответил на открытый вопрос из [`../OPEN-QUESTIONS.md`](../OPEN-QUESTIONS.md);
- выбрано умолчание, за которым стоит замер;
- проект отступает от [`../SPEC.md`](../SPEC.md) — даже если отступление технически правильное;
- выбрана одна из двух равнозначных технологий.
