# 0064. Данные остаются рядом с программой; обновление — распаковать поверх

**Дата:** 11.10.2026
**Статус:** принято
**Кто решил:** владелец счёта, 11.10.2026

## Вопрос

D-080: под Windows `userdata/` лежит внутри папки программы ([0003](0003-runtime-data-location.md)),
и обновление заменой папки уносит базу, настройки и файл токена. Как обновляться, не теряя данные.

## Варианты

| Вариант | Последствие | Цена вопроса |
|---|---|---|
| (а) Папка пользователя (`%APPDATA%`, `~/.local/share`) с переносом старых данных | Данные вне папки программы, замена папки безопасна структурно | Отказ от портативности ([0001](0001-packaging-nuitka-portable.md)); код переноса старых данных; «скопировал папку на флешку» перестаёт переносить историю |
| (б) Человек выбирает папку данных при первом запуске | Данные там, где он сказал | Лишний экран и лишний шанс ошибиться; тот же отход от портативности |
| **Данные рядом с программой, обновление «распаковать поверх»** | Ничего не меняется в раскладке | Удаление папки программы целиком уносит данные — защищают слова и плашка, не структура |

## Решение

Данные остаются рядом с программой. Обновление — распаковать новый архив поверх прежней папки
(`userdata/` в архиве нет, поэтому она не затрагивается). Программа, запущенная там, где в
`userdata/` нет ни базы, ни настроек, ни ключа брокера, показывает плашку «Данных нет.» с полным
путём, куда скопировать `userdata` из прежней папки; на новой машине это нормальный первый запуск.
README обеих поставок получили раздел «Как обновить программу до новой версии»: копия `userdata`
про запас, распаковка поверх, `userdata` не удалять, при удалении — вернуть из копии.

## Основание

Слова владельца счёта: «Данные остаются рядом с программой, как сейчас: портативная поставка,
решение 0001. Обновление — „распаковать поверх“». Больше доводов владелец не давал.
Довод команды: вариант без изменения раскладки не требует кода переноса и не трогает защиту
токена из 0003.

## Что это ломает

Не снимает мину D-080 структурно, а только словами и плашкой: данные по-прежнему внутри папки
программы, и удаление папки целиком их уносит. У AppImage `userdata/` лежит рядом с файлом
`.AppImage` и безопасна структурно. Zip Windows содержит верхнюю папку `Terminal`, поэтому
«Извлечь всё…» в папку-родителя, а не в саму `Terminal`. Разбор вариантов поставки —
`.docs/packaging/packaging-expert-2026-09-06-1322.md`.
Плашка надёжна только на первом запуске в пустой папке: этот же запуск заводит базу, и дальше
плашки нет, даже если данные не скопировали; частичный перенос, консольные ключи и Windows
вживую — не покрыты ([миниплан](../plans/d080-missing-data-notice.md)).
