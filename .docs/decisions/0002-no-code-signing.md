# 0002. Подписи кода не будет

**Дата:** 30.08.2026
**Статус:** принято
**Кто решил:** заказчик работ (владелец проекта)

## Вопрос

Без цифровой подписи Windows показывает предупреждение SmartScreen «Windows защитила
ваш компьютер» при запуске у нового пользователя и может заблокировать программу
через Smart App Control на Windows 11. Подписанные бинари также заметно реже получают
ложные срабатывания антивирусов.

Вариант 2026 года — Azure Trusted Signing, от ~$10/мес, но требует проверенного
юрлица или статуса самозанятого в США, Канаде, ЕС или Великобритании.

## Решение

**Подписи не будет.** Юрлицо под это не заводится, подписка не оформляется.
Вопрос закрыт и к обсуждению не возвращается.

## Следствия, которые надо отработать кодом и текстом

1. **Антивирус — единственный барьер.** Отсюда выбор Nuitka вместо PyInstaller
   ([решение 0001](0001-packaging-nuitka-portable.md)): нативный бинарь вместо
   загрузчика, попавшего в списки угроз.

2. **UPX-сжатие не используется** нигде и никогда: упаковщик — отдельный признак
   для эвристик.

3. **Имя и структура сборки стабильны** от релиза к релизу. Меняющееся имя
   исполняемого файла выглядит для репутационных механизмов как новая неизвестная
   программа каждый раз.

4. **Ложные срабатывания отправляются вендорам.** У всех крупных антивирусов есть
   форма подачи ложного срабатывания, разбор занимает дни. Это штатная процедура
   релиза, а не аварийная.

5. **В инструкции пользователя — отдельный раздел** с прямым объяснением
   и скриншотами: что показывает Windows при первом запуске, почему, и как пройти
   («Подробнее» → «Выполнить в любом случае»). Написано человеческим языком,
   без попытки это замять.

6. **Автообновление подписанным каналом невозможно.** Обновление — только по явному
   согласию пользователя, с показом того, что изменилось, и с возможностью отката.

## Что это ломает

Ничего из уже сделанного. Раздел про Azure Trusted Signing в
[`../DESKTOP-2026.md`](../DESKTOP-2026.md) §1 остаётся как справка о том, какой
вариант существовал и почему отклонён, — чтобы к вопросу не возвращались заново.
