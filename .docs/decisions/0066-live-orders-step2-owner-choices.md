# 0066. Боевые заявки, шаг 2: развилки Р1–Р10 выбраны владельцем

**Дата:** 28.10.2026 · **Статус:** принято · **Кто решил:** владелец счёта, диалог 27–28.10.2026
**Миниплан:** [`E4-live-orders.md`](../plans/E4-live-orders.md) §10 (развилки), §12 (шаг 2)

## Что решено

| Развилка | Выбор | Что это значит в коде |
|---|---|---|
| Р2 трейлинг | **сторож в программе** | уровень считает движок на закрытии свечи, как в симуляции; исполнитель судит касание по high/low **записанных минут** интервала, уровнем, поданным не позже начала минуты (зеркало `submitted_at > ready_at` модели), и на касании подаёт рыночный выход; касание внутри T отдаётся сделкой в `fills_at` по закрытой T. Снятие локальное, сработавший сторож — `ALREADY_TRIGGERED`, в т. ч. для `ARM` (`D-142`: строка в `engine/ports.py` и своя строка журнала, а не «позиция без сторожа»). Бой с трейлингом при свече не крупнее порога минуток запрещён (`D-141`) |
| Р1 неподвижный тейк | **лимитная у брокера** | заявка по уровню на сетке шага; снятие с ожиданием статуса `4`; «снята не нами» — остановка. **Уровень к шагу приводит движок** (от рынка, по `price_step`, рядом с `_time_exit_limit`), прогон судит касание тем же уровнем; при шаге 0 — как сейчас. Исполнитель цену не меняет |
| Р9 предохранители | **не возвращать** (`D-113` остаётся) | бой при выключенных разрешён; потолка объёма, дневного лимита и запаса средств нет |
| Р6 объём | **заявка на весь объём, без частичных для движка** | исполнитель собирает исполнения одной заявки в одну сделку (объём — сумма, цена — средняя) и отдаёт движку только при полном исполнении; частично исполненный тейк при снятии — остаток закрывается тем же выходом, движку одна сделка |
| §2.6 конец заявки после приёма | **остановка с причиной** | канала «заявка исчезла» нет; исполнитель бросает `engine.ports.ExecutionHalted` из `submit` или `fills_at`, движок пишет его причину своей строкой (не «исполнитель не ответил»), накопленные сделки отдаются раньше исключения; модель выдаёт этот исход по требованию теста; рыночная `submit` ждёт статуса `2` или `8`; частичное исполнение без конца — предел ожидания (настройка), снять остаток, `ExecutionHalted` |
| Р7 перезапуск в тот же день | **день из базы в движок** | счёт на утро, результат дня, дата тейка и выхода — значением при старте, как `on_funds`; правило «стоп после тейка» остаётся в движке |
| Сверка 0020 | **автоматически закрыть всё** | при расхождении позиции или заявок у брокера с движком: снять заявки, закрыть позицию по рынку, остановка; один раз, по свежему запросу (С2). Делает `app/` — это правит `ARCHITECTURE.md` §3 (сверка была за `engine/`): сделки «закрыть всё» пишутся в таблицу исполнений, день Р7 считается по ней, «Возобновить» — сброс и прогрев. **Уточнено 01.11.2026 (`/risk` К2):** продаётся только объём, подтверждённый двумя согласными чтениями портфеля **и** позицией по исполнениям, которые программа видела в потоке; не сходится — заявка не подаётся, остановка с обеими цифрами, закрывает владелец. «Закрыта» пишется только по исполненной закрывающей заявке и нулевой позиции после неё |
| Обрыв потока статусов, несвежая свеча | **пропустить сигнал, работать дальше** (01.11.2026) | `ExecutionRefused`, заявка не подана, строка «сигнал пропущен» с причиной; робот не встаёт (0017) |
| Касание трейлинга в догруженных минутах | **сразу выйти по рынку и работать дальше** (01.11.2026) | после восстановления связи исполнитель подаёт рыночный выход и отдаёт сделку движку свечой касания; позиция не остаётся без защиты |
| Р10 аварийный стоп | **не ставить** | пока программа закрыта или без связи, позиция без защиты; окно предупреждает при закрытии |
| Р3 выход по времени | **как в симуляции** (0062 §3, вариант А) | лимитная с пределом, единица — вопрос 26 (временно 10 шагов); не исполнилась — остановка, текст называет живую заявку у брокера (С9) |

## Что правит
* **0008** — посылка «тейк живёт у брокера» остаётся только для неподвижного тейка (Р1); трейлинг сторожит программа.
* **0017** — в бою заявка, закончившаяся после приёма, ведёт к остановке, а не к «сигнал пропущен».
* **`CLAUDE.md`, `/go-live`** — три предохранителя «до первого боевого запуска» владелец не возвращает; сказано один раз 28.10.2026.

## Что не закрыто
* Работает ли всё это у брокера — только на живом счёте (§9 плана).
* Пока программа закрыта, трейлинг не сторожится (Р2 + Р10).
