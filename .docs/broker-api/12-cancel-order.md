# Отменить заявку

URL: https://trade-api.bcs.ru/http/operations/cancel-order

```
POST
## https://be.broker.ru/trade-api-bff-order-details /api/v1/orders/cancel
```

Метод позволяет отменить собственную заявку по идентификатору. Поддерживаются заявки,
поданные через Trade API и МИ, со статусами `0` (Новая), `1` (Частично исполнена),
`5` (Заменена) и `10` (Ожидает подтверждения новой заявки). Для заявок через МИ данные
заявки предварительно получаются по биржевому идентификатору.

## Request — Body, required

| Поле | Тип | Обяз. | Описание |
|---|---|---|---|
| `orderIdType` | string | нет | `1` — `clientOrderId` исходной заявки в формате `UUID` (по умолчанию); `2` — биржевой `orderId` строкой. **Default:** `1` |
| `orderId` | string | да | Идентификатор отменяемой заявки. При `orderIdType = "1"` — `clientOrderId` исходной заявки (UUID); при `"2"` — биржевой идентификатор `ГГММДД-КодКласса-НомерЗаявки` |
| `clientOrderId` | uuid | да | Уникальный идентификатор **запроса на отмену** — генерируется вами. Используется для отслеживания и предотвращения дублирующих заявок |

```json
{ "orderIdType": "1", "orderId": "string", "clientOrderId": "3fa85f64-5717-4562-b3fc-2c963f66afa6" }
```

## Responses

**200 OK** — `clientOrderId` uuid (UUID запроса на отмену), `status` string (`OK`)

**400 / 401 / 403 / 404 / 422 / 429 / 500** — общая форма отказа плюс `USER_NOT_FOUND`.

Base URL `https://be.broker.ru/trade-api-bff-order-details`, Bearer JWT.

---

## Зачем это нам

⚠️ **У отмены свой `clientOrderId`, отдельный от идентификатора отменяемой заявки.**
Путаница здесь стоит дорого: передать в `clientOrderId` идентификатор исходной
заявки — значит послать запрос, который не то отменяет и не так отслеживается.
Два разных поля в одном теле, оба UUID, имена похожи.

**Прямое отношение к тейк-профиту (решение 0008).** Тейк — это заявка на стороне
брокера, а не расчёт внутри программы. Снятие тейка при выключении робота,
при перевороте и при закрытии позиции идёт через этот метод. Отсюда:

⬜ повтор отмены при обрыве связи безопасен только с **тем же** `clientOrderId`;
⬜ отмена уже исполненной заявки вернёт `404` или `422` — это **не ошибка
   программы**, а гонка: тейк успел сработать. В журнал такое пишется
   человеческим языком, а не кодом;
⬜ ⚠️ **снятую руками заявку движок не заметит** и будет считать сторожа живым —
   это уже записано в `ui/notices.py` и остаётся верным.
