# Получить обезличенные сделки

URL: https://trade-api.bcs.ru/http/market-data/get-last-trades

```
POST
## https://be.broker.ru/trade-api-market-data-connector /api/v1/last-trades
```

Метод предназначен для получения истории обезличенных сделок за текущую торговую сессию.

## Request — Body (application/json), required

**startDateTime** date-time Начало периода выборки
**endDateTime** date-time Конец периода выборки
**classCode** string **required** `non-empty` Код класса ценной бумаги
**ticker** string **required** `non-empty` Тикер инструмента
**side** string Направление сделки — `1` Покупка, `2` Продажа

```json
{
  "startDateTime": "2024-07-29T15:51:28.071Z",
  "endDateTime": "2024-07-29T15:51:28.071Z",
  "classCode": "string",
  "ticker": "string",
  "side": "1"
}
```

## Responses — 200 OK

**records** object[]
* **dateTime** date-time Дата и время сделки
* **side** string Направление — `1` Покупка, `2` Продажа
* **price** number Цена сделки
* **volume** int64 **Объем сделки в валюте инструмента**
* **quantity** int64 **Количество в штуках**

```json
{
  "records": [
    { "dateTime": "2024-07-29T15:51:28.071Z", "side": "1", "price": 0, "volume": 0, "quantity": 0 }
  ]
}
```

## 400 / 429 — общая форма отказа, см. `03-limits.md`

Base URL `https://be.broker.ru/trade-api-market-data-connector`, Bearer JWT.

---

## Зачем это нам — здесь прямое подтверждение находки по объёму

Схема **прямым текстом разделяет два поля**:

* `volume` — «Объем сделки **в валюте инструмента**»;
* `quantity` — «Количество **в штуках**».

Это подтверждает замер 04.09.2026 по потоку свечей: там пришло единственное поле
`volume`, и в минуте 05:38 оно равнялось 30 579 800 при цене 224 850, то есть
**оборот в валюте, а не количество контрактов**. В нашей базе `minute_candle.volume` —
контракты (значения 1…43 146 при цене 233 000), источник ISS.

Вывод для стыка живых данных с историей: единицы **разные**, и это не догадка,
а два независимых подтверждения — замер потока и словарь полей брокера.

⚠️ У свечи БКС поля `quantity` нет вовсе — только `volume`. Значит из свечи количество
контрактов **точно** не восстановить, только делением оборота на цену, с погрешностью
от разброса цены внутри минуты. Этот метод (обезличенные сделки) даёт точное
`quantity`, но лишь **за текущую торговую сессию** и по каждой сделке отдельно —
как источник объёма для свечей он дорог, но годится как **эталон для проверки**
пересчёта на одном дне.
