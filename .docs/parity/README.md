# Отчёты сверки с прототипом

Сюда `parity-auditor` (`/parity`) складывает отчёты сравнения «Терминала»
с действующим прототипом стратегии.

Имя файла: `YYYY-MM-DD_период_настройки.md` — **латиницей**, правило 6 `CLAUDE.md`.
Дата, период и настройки в имени пишутся латиницей и цифрами; русские слова
в имени файла запрещены, в содержимом — обязательны.

Формат отчёта и протокол сверки — [`../PROTOTYPE.md`](../PROTOTYPE.md) §7
и `.claude/agents/09-parity-auditor.md`.

Сырые JSON-выгрузки прогонов в git не попадают (`.gitignore`), только отчёты в Markdown.
