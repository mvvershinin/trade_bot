# B-069 — загрузка и прогон по каждому контракту периода

**Чья боль.** Владелец счёта выбрал период с 17.06 и не может понять, что программа
загрузила и на чём считала: грузится только код из настроек, хвост архивного MXU6
не грузит никто, прогон проходит дни без свечей молча (05.09–16.09, ни слова).

**Что делается.**
1. Окно «Загрузить историю»: дата «С какого дня» действует для обоих вариантов,
   `request()` кладёт `since` всегда; `PickOnClick` убран (поле не бывает выключенным).
2. `HistoryPort._load_contract`: цепочка удлиняется назад до начала отрезка
   (`market.contracts.chain_covering`), затем `pieces(since, сегодня)` и по каждому
   куску `load_contract_minutes` (новое необязательное `ContractRequest.since`).
   «Заново» снимает отметки по каждому куску. Без `since` (автопереход) — как раньше.
3. Сверка после загрузки (`market.contracts.check_days`, `MarketWorker.check_days`):
   дни с объёмом в дневных свечах биржи против дней с минутами в базе; недостающие —
   строкой в `trouble`, `ok=False`, отметки сняты. Итог: «Загружено: MXU6 18.06–16.09
   (65 из 65 …) · MXZ6 …».
4. `app/stitched.py::load_pieces`: будние дни куска без бара, раньше сегодня и без
   отметки `data_day` — диапазоны, заметка «MXU6: нет свечей за …» → журнал прогона
   и ⚠ в «По контрактам».
5. Строка «Считается на: …» из кусков — шапка отчёта о прогоне и «Отчёты».

**Что ломается → чем обнаружено.**
- Загрузка тянет только код из настроек → сторож A (порт, подставная биржа: запрошены
  минуты MXM6, MXU6, MXZ6 своими днями).
- Сверка молчит о днях без минут / не снимает отметки → сторож B1 (`check_days`).
- Дыра внутри куска не названа → B2 (`load_pieces`); названа, но не отдана в журнал
  и `problems` → B3 (мутация «посчитали, не отдали»).
- Ложная тревога на выходных и праздниках с отметкой → B4.
- Строка «Считается на:» не дошла до отчёта → сторож на `BacktestReport`.
- Автопереход при запуске сломан → прежние тесты `test_ui_contract_load.py`.
- Торговая логика задета → проверка-образец `tests/test_golden_deals.py`.

**Что НЕ закрывает.**
- «Из N торговых дней биржи» в прогоне не пишется: прогон к бирже не ходит.
- Праздник в отрезке, грузившемся только живым потоком (без отметки `data_day`),
  даст ложную тревогу в прогоне.
- Торги выходного дня без свечей и без отметки прогон не ловит (смотрит пн–пт).
- Неполный день не ловится ни сверкой, ни прогоном: сверка по дням, не по минутам.
- Рубеж (0049 §1) не меняется: 17.06 — ещё MXM6, 17.09 — уже MXZ6.
- «Торговых дней: N» в шапке отчёта считает календарные даты со свечами вместе
  с торгами выходного дня (17.06–09.10: 107 против 83 у биржи) — не тронуто.
  «Считается на:» считает будни, как биржа и сверка загрузки.

**Как проверено.** Сторожа A, B1–B4 и строки отчёта; полный `pytest`; путь человека
на копии настроек без баз: загрузка с 17.06, снимок итога, сверка дней с ISS
скриптом по каждому контракту, прогон тестера и снимок шапки.
