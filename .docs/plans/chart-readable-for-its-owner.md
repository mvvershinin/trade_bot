# Миниплан: график читается человеком, а не разработчиком

Задача — `ROADMAP.md`, «Первая задача», пункт 7. Просьба владельца счёта
05.09.2026 со снимком: «это сейчас максимально запутано и непонятно мне,
или легенду расширь что ли».

Уточнение 05.09.2026 по перекрестью, дословно: «пересечение двигается вместе
с мышью… без кликов, просто модернизированный курсор».

## Что этот код делает и чья это боль

Боль одна и названа владельцем счёта: он смотрит на собственный график
и не понимает, что видит. На экране шесть видов меток, два вида пунктира,
две сплошные линии и легенда одной строкой мелким текстом, которая не
объясняет ни одной формы.

Три части:

* **(а) перекрестье** — тонкие пунктирные линии за курсором до границ поля
  свечей, с подписью времени внизу и цены справа. Без кликов;
* **(б) разбор участка** — выделение мышью разворачивает сделки этого куска:
  вход, выход, причина выхода, цены, результат;
* **(в) легенда** — каждая метка, которая может появиться, объяснена словом.

## Что здесь способно сломаться — списком, до выбора решения

1. **Три поведения на одной мыши.** Панорама (левая кнопка) уже принята
   владельцем счёта. Добавляются выделение и перекрестье. Любое из трёх
   способно съесть события двух других — молча, потому что событие мыши,
   обработанное не тем кодом, не падает.
2. **Перекрестье над пустым местом** (`B-005`): места есть и у свечи,
   и у пропущенной. Подпись времени над пустым местом читается как
   «здесь свеча в 13:45», хотя её нет.
3. **Перекрестье за краем ряда.** `_place_at_x` возвращает номер и там, где
   мест нет вовсе; `_stamp_at` время в этом месте продолжит наружу. Подписать
   его — соврать о времени, которого на бирже не было.
4. **Выделение по номерам мест, а не по времени.** В выделение попадает
   пропуск; сделки отбираются по времени, а границы приходят из координат
   экрана. Переводить одно в другое можно двумя разными способами и получить
   соседний кусок.
5. **Разбор сделок начинает считать.** Причина выхода, цены и результат
   приходят готовыми (`TradeRow`). Любая арифметика по деньгам здесь —
   вторая версия правды на экране.
6. **Легенда расходится с графиком.** Формы меток нарисованы в одном месте,
   легенда — в другом; правка одной из них молча оставляет вторую старой.
   Тот самый паттерн «перечисление в двух местах»
   (`quality/code-size-2026-09-03.md` §8).
7. **Легенда неполна.** Появился вид метки — про него забыли. Пять случаев
   `DOMAIN.md` §8 обязаны быть на экране все.
8. **Два пунктира спорят.** Прогноз рисуется пунктиром, границы пропуска —
   пунктиром, перекрестье просится третьим.
9. **Верхняя полоса не знает темы** (`D-016`): светлый рубец на тёмном окне.
10. **Принятое глазами.** `B-008` (свеча на своей минуте), `B-009` (масштаб),
    `B-005` (пропуск), `B-013` (дата читается), наведение — всё это трогается
    той же мышью и той же отрисовкой.

## Чем каждое будет обнаружено

| № | Чем ловится |
|---|---|
| 1 | тесты: панорама сдвигает вид левой кнопкой; правая кнопка вид **не** двигает; перекрестье появляется без единой кнопки |
| 2 | тест: над пустым местом подпись времени содержит «данных нет» |
| 3 | тест: за краем ряда подписи времени нет вовсе |
| 4 | тест: в разбор попадают сделки выделенного куска и не попадают сделки соседнего |
| 5 | тест `test_ui_no_trading_logic`; отказ считать итог назван вслух в докстринге |
| 6 | одна функция рисует и метку на графике, и значок легенды; тест сравнивает нарисованное |
| 7 | тест на полноту таблицы: у каждого `MarkerKind` есть строка легенды |
| 8 | перекрестье отличается не только пунктиром: подписи на осях и своя частота штриха |
| 9 | тест контраста по **нарисованной** картинке, порог 4,5:1, обе темы |
| 10 | прогон `tests/test_ui_*` целиком плюс мутации по каждому сторожу |

## Чего решение не закрывает

* **Веб-поверхность.** Файла библиотеки нет на диске, `is_available()`
  отказывает, ни одна строка страницы не исполняется. Перекрестье там штатное
  (`crosshair` библиотеки), выделение и расширенная легенда **не сделаны**.
* **Итог по выделенным сделкам в рублях** не показывается намеренно (п. 5).
* `D-014`, `D-015` (две строки сведений при живом веб-графике) не трогаются.

## Чем проверяется

```
.venv/bin/python -m pytest tests/test_ui_*.py tests/test_function_size.py -q
.venv/bin/ruff check ui/          # было 151
.venv/bin/mypy                    # было 31 по ui/
```

Снимки экрана в обеих темах — в `.docs/ui/`.

## Решения, принятые здесь и названные вслух

1. **Легенда раскрыта по умолчанию**, сворачивается кнопкой. Владелец счёта
   сейчас график прочитать не может; закрытая по умолчанию панель — это панель,
   которую он не найдёт.
2. **Слой «Прогноз» выключен по умолчанию.** Шесть видов меток сразу —
   и есть причина жалобы. Слой факта в прогоне заполнен всегда
   (`app/convert.py::markers_and_paths`), поэтому пустого экрана не будет.
3. **Кнопки мыши разведены:** движение — перекрестье; левая — панорама;
   правая либо Shift+левая — выделение участка.
4. **Перекрестье подписывает обе оси** — время внизу, цену справа.
