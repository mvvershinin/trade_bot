### 2. 🟡 Low — `SettingsStore.patch` молча считает успехом нечитаемый файл

**[app/settings_store.py `patch`: `except (OSError, UnicodeDecodeError, json.JSONDecodeError): return ""`
и `if not isinstance(stored, dict): return ""`]**

Если файл испорчен после запуска, на переходе с истёкшего контракта ничего не пишется.
Пустая строка при этом значит «успех»: `remember` ставит `kept[0] = wanted`, а журнал
говорит «Инструмент в настройках сменён и записан в файл». Следующий запуск начнётся
с истёкшего кода. Вероятность мала: файл должен сломаться между запуском и сменой
контракта. Нарушено правило 13. Требование: вернуть фразу.
Попутно: `patch` переукладывает весь файл (`indent=2, sort_keys=True`), поэтому обещание
докстринга «остальное — байт в байт» выполняется только для файла, записанного самой программой.
