### Э2 — живые котировки ⬜ ждёт буднего дня

В графике идут котировки в реальном времени, свеча текущей минуты **растёт на глазах**,
а не появляется готовой по закрытии минуты.

`LiveFeed` написан, подписка и переподключение есть.

**Эталон — терминал брокера.**

**Приёмка этапа, слова владельца счёта 04.09.2026:** открыть «Терминал» и живой терминал БКС
рядом и смотреть одновременно. В реальном времени обязаны совпасть: положение свечей по оси,
метка текущей минуты, момент появления новой свечи, цена закрытия предыдущей. Расхождение
в одну минуту, пропуск или склейка — этап не принят.

Это лучшая проверка из возможных: она ловит сразу и сдвиг времени, и дыры в данных,
и запаздывание, причём глазами, без единого теста.

**Что мешает сегодня** (замечено 04.09.2026 по снимку экрана, подробности в `BACKLOG.md`):

  данных отсутствует, но свечи нарисованы встык, без разрыва
Этот один — **часть этапа**, а не долг рядом с ним: без него этап показать нельзя.
(`B-001`, девять падавших тестов живого потока; `B-006`, догрузка пропущенного;
`B-007`, живая текущая свеча, — закрыты 04.09.2026.)

останавливал торговлю без единой ошибки в коде: `D-046` — ГО под контракт

## Как вести этот файл

**Добавлять сюда** — только новый этап, то есть новый показываемый результат.

**Не добавлять сюда:**

| Что нашли | Куда |
|---|---|
| Баг | `BACKLOG.md`, раздел «Баги» |
| Технический долг, находка ревью | `BACKLOG.md`, раздел «Долги» |
| Вопрос к владельцу счёта | `OPEN-QUESTIONS.md` |
| Принятое решение с обоснованием | `decisions/NNNN-название.md` |
| Замер, порог, цифра | `quality/` |

Правило простое: **в плане только будущее, которое можно показать. Всё остальное — в других
файлах.**

Когда этап закрыт — строка переезжает в `CHANGELOG.md` с датой, а не остаётся здесь с галочкой.
