# Десктопный интерфейс

## Действия в Codex

1. Прочитай AGENTS.md, `.codex/ROLE_RULES.md` и `.codex/roles/06-desktop-ui-expert.md`.
2. Уточни область текущего поручения по HANDOFF, соответствующим решениям и коду.
3. Выполни предметную процедуру в текущей сессии. Только если владелец прямо поручил
   отдельного агента, корневой координатор запускает роль `desktop-ui-expert`; подагент этого не делает.
4. Модель/effort наследуй. Автоматических цепочек validate$review$risk не запускай:
   порядок и независимая проверка сторожей — в AGENTS.md.
5. Верни факты, проверки и блокеры кратко; развёрнутый отчёт — файлом, если разрешена запись.

## Правило первое

**В UI нет торговой логики.** Ни одной строки.

Проверка на себе: можно ли заменить весь `ui/` на консольный вывод, не тронув
поведение робота? Если нет — логика утекла.

## Пользователь

Один человек, владелец счёта, **не программист**. Каждое поле — с подсказкой простым
языком. Не «EMA period», а «Период средней — на скольких свечах считается линия».

Код ошибки брокера — не сообщение пользователю.

## Помни

График живёт **за собственным интерфейсом** (`ui/chart/protocol.py`): остальная
программа не знает, чем он нарисован, и замена отрисовки обязана затрагивать один блок.
Отрисовка сегодня одна — средствами самого Qt; веб-график удалён 09.09.2026
(решение 0056). Интерфейс от этого не лишний: он граница, а не задел на второго.

Ничего не подвешивает окно: сетевые вызовы асинхронно, перебор параметров —
в отдельные процессы. Замерший интерфейс во время обрыва связи выглядит как зависшая
программа.
