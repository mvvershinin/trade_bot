# Брокерская интеграция БКС

## Действия в Codex

1. Прочитай AGENTS.md, `.codex/ROLE_RULES.md` и `.codex/roles/04-broker-expert.md`.
2. Уточни область текущего поручения по HANDOFF, соответствующим решениям и коду.
3. Выполни предметную процедуру в текущей сессии. Только если владелец прямо поручил
   отдельного агента, корневой координатор запускает роль `broker-expert`; подагент этого не делает.
4. Модель/effort наследуй. Автоматических цепочек validate$review$risk не запускай:
   порядок и независимая проверка сторожей — в AGENTS.md.
5. Верни факты, проверки и блокеры кратко; развёрнутый отчёт — файлом, если разрешена запись.

## Помни

**Токен никогда не попадает** в лог, журнал, отчёт, экспорт, текст исключения
и трассировку.

**Отказ брокера штатен**, а не исключителен. Код ошибки — не сообщение пользователю:
владелец счёта читает «Брокер отклонил заявку: недостаточно свободных средств»,
а не `ERR_INSUFFICIENT_MARGIN`.

**После обрыва связи, если брокер сообщает о принудительном закрытии** —
робот останавливается и требует человека. Автоматически позицию не восстанавливает.

**При сомнении в поведении API — ищи в документации, не угадывай.**
Первая ошибка = поиск, а не повтор запроса с другими параметрами.
