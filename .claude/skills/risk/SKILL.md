# Аудит безопасности денег

## Действия

1. Собери изменение: `git diff`, `git diff --staged` или указанные файлы
2. Запусти Agent: `subagent_type` general-purpose, `model` opus,
   правила из `.claude/agents/08-risk-security-officer.md`
3. Верни отчёт с вердиктом BLOCK / REQUEST_CHANGES / APPROVE
   и состоянием каждого предохранителя

## Когда обязателен

Любое изменение, трогающее: токен, подачу заявки, расчёт объёма, потолок объёма,
дневной лимит убытка, проверку обеспечения, переключение боевого режима.

## Предохранители — все обязаны быть до первого боевого запуска

⬜ Боевой режим не включается на токене «только чтение»
⬜ Потолок объёма проверяется **после** любого расчёта, включая расчёт от процента риска
⬜ Дневной лимит считается от счёта **на утро** и внутри дня не пересчитывается
⬜ Свободные средства видны **до** подачи заявки, а не из отказа брокера
⬜ Один экземпляр программы (мьютекс / lock-файл)
⬜ После принудительного закрытия брокером — остановка, а не восстановление позиции
⬜ Токен не утекает в логи, отчёты, исключения, фикстуры

**Отказ по потолку или по средствам — это событие журнала с причиной,
а не тихое ничегонеделание.**
