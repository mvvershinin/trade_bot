# Десктопный интерфейс

## Действия

1. Прочитай `.docs/SPEC.md` §4.5–4.6, `.docs/DESKTOP-2026.md` §6–7,
   `.docs/ARCHITECTURE.md` §5
2. Запусти Agent: `subagent_type` general-purpose, `model` opus,
   правила из `.claude/agents/06-desktop-ui-expert.md`

## Правило первое

**В UI нет торговой логики.** Ни одной строки.

Проверка на себе: можно ли заменить весь `ui/` на консольный вывод, не тронув
поведение робота? Если нет — логика утекла.

## Пользователь

Один человек, владелец счёта, **не программист**. Каждое поле — с подсказкой простым
языком. Не «EMA period», а «Период средней — на скольких свечах считается линия».

Код ошибки брокера — не сообщение пользователю.

## Помни

График живёт **за собственным интерфейсом**: ТЗ предусматривает запасной переход
с веб-графика на pyqtgraph, и замена обязана затрагивать один блок.

Ничего не подвешивает окно: сетевые вызовы асинхронно, перебор параметров —
в отдельные процессы. Замерший интерфейс во время обрыва связи выглядит как зависшая
программа.
