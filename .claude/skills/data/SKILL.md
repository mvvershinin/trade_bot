# Данные и хранилище

## Действия

1. Прочитай `.docs/SPEC.md` §4.7, `.docs/DOMAIN.md` §6,
   проверенный загрузчик котировок в локальном архиве `reference/` — **этот код уже проверен и переиспользуется**
2. Запусти Agent: `subagent_type` general-purpose, `model` sonnet,
   правила из `.claude/agents/05-data-expert.md`

## Особенности, стоившие времени

- **Пятиминутки ISS не отдаёт вообще.** Только минутные, часовые, дневные —
  нужный размер собирается из минуток
- Внутридневная история **ограниченной глубины** (~2 месяца для Min5).
  Прямо ограничивает независимую проверку
- ISS иногда отдаёт JSON **с BOM** — транзиентная ошибка, чанк перезапрашивается
- Справочник инструментов у брокера грузится 20–60 секунд. Пустой список до этого —
  ожидание, а не ошибка

## Помни

Собранные данные уже **совпали с эталоном построчно**. Это совпадение нельзя потерять —
любое изменение сборки таймфрейма закрывается сверочным тестом.

Пересборка таймфрейма из уже пересобранных свечей запрещена: собираем только из минуток.
